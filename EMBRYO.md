# Embryo Machine Stats

Embryo Machine Stats is Embryo-Zero's fork of [node_exporter](https://github.com/prometheus/node_exporter) (b653b21, commit b653b21). It does CPU, memory, disk, network numbers from each machine.

- Our changes live on the `embryo` branch. The original license files (LICENSE, NOTICE) are unchanged.
- Legal notes: LEGAL.md. Dated list of our changes: CHANGES-EMBRYO.md.
